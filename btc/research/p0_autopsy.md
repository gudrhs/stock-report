# P0 부검 — 에이전트는 왜 매수·보유와 거의 같았고, 2025~26년엔 왜 한 번도 팔지 않았나

> **사후(post-hoc) 연구입니다.** 잠금 구간(2025-01 ~ 2026-09)은 이미 열렸고, 이 노트는 2017~2026 전체를
> 결과를 본 뒤에 분석합니다. 여기 숫자는 P0의 판정(사전 등록 규칙 불통과)을 바꾸지 않으며, 끝의 두 예비 실험도
> 판정용이 아니라 다음 설계를 고르기 위한 것입니다.
>
> 기준: phase 0, 편도 비용 0.15%, 판단 비용 c_dec 0.3% → 문턱 th = −100·ln(1−0.003) = **±0.3005**.
> 표본외 2017-01-01 ~ 2026-09-25. "중앙값"은 반복 10개의 중앙값. 헤드라인 반복은 r6.

## 요약

1. **재현은 비트 단위로 됩니다.** 10개 반복 × 117개월 워크포워드를 저장된 시드로 다시 돌린 Δ가 저장본과 전부
   정확히 같았습니다(최대 차이 0). 그래서 아래의 거부된 모델과 반사실(counterfactual)은 "그때 실제로 나왔을 모델"입니다.
2. **Δ는 대부분 무거래 띠 안에 있습니다.** 해마다 봉의 47~91%에서 |Δ| ≤ 0.30이었고, 매도 구역(Δ < −0.30)은
   2018년에 5.4%, 다른 해에는 0~2.6%, **2021·2024·2025·2026년에는 0%**였습니다. 분포 중심이 +0.03~+0.32라서
   한번 사면 거의 팔지 않습니다. 벨만 식에서 정확히 나오는 항등식
   `Δ_t = κ·E[m_t] + γ·E[clip(Δ_{t+1}, −th, +th)]` 때문에, **팔려면 모델이 앞으로 약 5.5일 동안 연율 −20%보다 나쁜
   추세가 이어진다고 믿어야** 합니다. 모델은 한 번도 그렇게 믿지 않았습니다.
3. **2025~26년에는 게이트가 해가 되지 않았습니다. 결과에 아무 영향이 없었습니다.** 거부된 2025년 1월과 2026년 1월
   새 모델(10개 반복 모두)을 썼어도 2025~26년 노출은 100%였고, 결과는 매수·보유와 같습니다(−9.8%, 최대낙폭 −53.1%).
   게이트를 끈 세 가지 반사실(V1·V2·V3)도 10/10 반복에서 똑같았습니다. 2025~26년의 이어학습 거부 17건은
   **게이트 계산 방식이 만든 착시**였습니다. 불일치를 현금(p0=0)에서 시작해 재기 때문에, 실제 보유(코인)에서
   시작하면 불일치는 0%입니다(2024-06 한 건을 더한 18건 모두).
4. **실패는 모델 자체에 있습니다.** 2022·2025·2026년 1월 새 모델과 2026-09 최종 모델을 2017~2026의 모든 봉에
   적용하면, 학습 때 본 2018·2022년 약세장 봉에서도 Δ < −0.30이 나온 비율은 **0%**입니다(노출 97~100%).
   이 모델들은 어떤 과거 국면에서도 팔지 못합니다.
5. **2017~2026 전체로 보면 게이트는 약간 도움이 됐습니다.** 게이트를 모두 끄면 샤프 중앙값이 −0.023 낮아지고
   (10개 중 8개 반복에서 낮아짐), 그 차이는 거의 전부 2022년에서 옵니다. 2022년 1월 새 모델은 늘 보유하려는
   모델이었고, 게이트가 이것을 막아 이전 계통이 조금이나마 팔 수 있었습니다(2022년 −61% 대 −64%).
6. **Δ는 주로 추세 지표가 정합니다.** 22개 지표로 선형 설명력 R² 0.62(2차항 포함 0.69)입니다. 가장 큰 축은
   종가 대 50일선(SMA300)과 200일선(SMA1200)입니다. 그러나 **예측력은 없습니다.** 연도별 IC(Δ, 실현 할인수익)는
   −0.17 ~ +0.10이고, 가장 크게 음(−)이었던 해가 2018·2022년 약세장(−0.17)이었습니다. 보유 판단이 C>SMA1200 규칙(B2)과 일치한 비율은
   65%뿐이고, 200일선 아래에서도 81% 보유했습니다.
7. **낙폭 감소 8.4%p(−83.4% → −75.0%)는 전부 2018년에서 왔습니다.** 2020년 폭락과 2021년 5~7월 폭락,
   2025~26년 하락 때는 100% 보유였고, 2022년에는 1.7%p만 줄였습니다. r6의 최대낙폭 −75.0%는 바로 이 2022년
   구간에서 나옵니다. 하락 구간에서 번 로그 초과수익 +1.20은 상승 구간에서 −1.20으로 그대로 돌려줬습니다.
   B2(+4.15 / −4.16)와 같은 모양의 "보험"이고, 크기만 약 1/3.5입니다.
8. **예비 실험(3개 시드).** Huber 손실 δ를 1에서 10으로 키우면 노출이 0.92에서 0.80으로 줄고 1월 게이트도
   7/10에서 9/10으로 더 통과합니다. 그러나 샤프는 나아지지 않았고(중앙값 1.04 → 0.96), 2026년에는 여전히 100% 보유였습니다.
   최근 가중 표본을 균등 표본으로 바꾸면 아무것도 바뀌지 않았습니다. **보유 편향은 손실 함수 탓이 일부이고,
   나머지는 신호가 없는 탓입니다.**

## 0. Δ를 읽는 법 — 비용 분해에서 나오는 정확한 항등식

P0의 가치는 `U(s,a) = κ·a·m + γ·max_a' [κ|a'−a|ln(1−c) + U(s',a')]`입니다. 두 행동의 차 Δ = U1 − U0를
정리하면 근사 없이 다음 식이 됩니다(th = −κ ln(1−c)).

```
Δ_t = κ·E[m_t | s_t] + γ·E[ clip(Δ_{t+1}, −th, +th) | s_t ]
```

- 다음 봉에도 계속 보유할 상태라면 Δ ≈ κE[m] + γ·th ≈ **+0.31**입니다. 계속 현금일 상태라면 ≈ κE[m] − 0.29입니다.
  한 봉 예측 |κE[m]|이 0.05 안팎이므로 Δ는 거의 항상 [−0.35, +0.35] 근처에 머뭅니다.
- 띠 안의 정상상태에서는 Δ = κμ/(1−γ) = 33·κμ입니다. 따라서 매수·매도 문턱을 추세로 바꾸면
  **μ = ±th·(1−γ)/κ = ±0.009%/봉 ≈ 연율 ±20%**(로그)입니다. P0의 규칙은 곧 "모델이 믿는 앞으로 약 33봉의 추세가
  연율 +20%를 넘으면 사고, −20% 밑이면 팔고, 그 사이면 그대로"입니다.

## 7. 다음 강화학습 설계에 주는 함의 — 검증할 수 있는 가설

각 항목에 사전 등록할 지표를 붙였습니다. 모든 비교는 B2(샤프 1.12, 최대낙폭 −67%)와 B&H를 기준으로 합니다.

1. **신호가 먼저입니다.** P0의 조건부 Δ는 IC ≈ 0이고, 비용과 규칙을 어떻게 바꿔도(격자 12개, PBO 0.74) 결과가
   같았습니다. *가설 H1*: 같은 22개 지표로 **지도학습 예측**(앞으로 30·90일 로그수익, 월간 워크포워드)을 했을 때
   2017~2024 IC가 0.05를 넘지 못하면, 어떤 강화학습 변형도 B&H 대비 샤프 +0.1을 넘지 못합니다.
   → 강화학습 전에 싼 "예측력 게이트"를 둡니다.
2. **판단 간격과 지평을 신호의 시간 척도에 맞춥니다.** Δ 변동을 설명하는 것은 50·200일선(ma_1200, x_300_1200)인데,
   판단은 4시간마다, γ = 0.97(5.5일)입니다. *H2*: 일봉 판단 + γ_일 ∈ {0.97, 0.99}(지평 1~3개월)이면
   ① 30~90일 IC가 4시간봉 P0보다 높고 ② 연간 매도·매수 횟수가 줄며 ③ 띠 안 체류가 50% 아래로 내려갑니다.
3. **손실을 평균에 맞춥니다.** Huber(δ=1, % 단위)는 문턱 크기의 절편 편향을 만듭니다. *H3*: MSE(또는 κ를 10으로
   낮춰 Huber가 사실상 제곱이 되게)이면 Δ 보정 기울기(예측 Δ 10분위 대 실현 G)가 1에 가까워지고 1월 게이트 통과가
   늘어납니다(예비 실험: 7 → 9/10). 성과 개선은 기대하지 않고, "Δ가 벨만 식이 말하는 뜻을 갖게 하는" 위생 조치입니다.
4. **이진 행동과 띠를 버리고 비율 노출을 씁니다.** 항등식 때문에 Δ는 ±th 근처에 몰리고, 보유가 상태가 아니라
   경로로 정해집니다(띠 안 47~91%). *H4*: 행동 {0, 0.25, 0.5, 0.75, 1}이나 연속 비중(거래는 목표와의 차이가 band를
   넘을 때만)이면, 같은 예측으로 ① 약세장(2018·2022·2025-10~2026-07) 평균 노출이 B&H보다 10%p 이상 낮고
   ② 노출과 G의 상관이 양(+)입니다. 비교 대상은 B7(변동성 목표)과 B8(같은 평균 노출의 고정 비율)입니다.
5. **목표가 낙폭 관리라면 보상에 넣습니다.** 로그자산 보상에 이진 보유를 쓰면, 추세가 강한 자산에서는 B&H가
   거의 최적입니다. P0가 한 일은 결국 "작은 보험"(하락에서 +1.2, 상승에서 −1.2)이었습니다.
   *H5*: 보상 = 로그수익 − λ·(낙폭 증가분) 또는 CVaR 벌점이고, λ를 {0.5, 1, 2} 중 사전 등록한 하나로 두면
   2017~2024 최대낙폭이 B2보다 작으면서 샤프가 B2 이상입니다. 그러지 못하면 규칙(B2/B7)을 쓰는 편이 맞습니다.

   ② 1월 점검은 "최근 2년 노출 ≤ 95%"가 아니라 **매도 능력**을 봅니다. 예: 고정된 과거 약세장 봉(2018·2022의 지표만)에서

7. **학습 분포.** 균등 표본은 효과가 없었으므로, 절편을 낮추는 길은 최근 가중이 아니라 **약세장 표본 수를 늘리는**

```bash
# 모두 btc/research/ 아래에만 씁니다 (btc/*.py·tests·data/btc는 건드리지 않음, 감사 로그에도 쓰지 않음)
OMP_NUM_THREADS=1 python -m btc.research.p0_autopsy_replay --reps 0 6 1 2 3 --variants V0 V1 V2 V3   # 반복당 변형 하나에 약 2.3분
OMP_NUM_THREADS=1 python -m btc.research.p0_autopsy_replay --reps 9 8 7 5 4                          # (프로세스 2개로 나눠 실행)
OMP_NUM_THREADS=1 python -m btc.research.p0_autopsy_ftgate --reps 0 1 2 3 4 6 7 8 9                 # 이어학습 게이트 착시 (~6분)
OMP_NUM_THREADS=1 python -m btc.research.p0_autopsy_pilot_huber                                      # 예비 실험 (~9분)
OMP_NUM_THREADS=1 python -m btc.research.p0_autopsy_pilot_recency                                    # 예비 실험 (~3분)
OMP_NUM_THREADS=1 python -m btc.research.p0_autopsy_analysis                                         # (1)~(6) → analysis.json
python -m btc.research.p0_autopsy_tables                                                             # 표 출력
```

| 파일 | 내용 |
|---|---|
| `p0_autopsy_common.py` | 회계(`evaluate.Window`와 같은 계산, 감사 로그 없음), `replay()`(= `monthly_update`에 게이트 켜기/끄기), G 계산 |
| `p0_autopsy_replay.py` | V0~V3 워크포워드, V0는 저장본과 비트 일치 확인 + 거부된 후보의 Δ와 2018·2022·2025·2026년 1월 모델 저장 |
| `p0_autopsy_ftgate.py` | 이어학습 거부의 불일치를 현금 시작 대 실제 보유 시작으로 다시 계산 |
| `p0_autopsy_analysis.py` | 1~6절 분석 → `out/p0_autopsy/analysis.json` |
| `p0_autopsy_pilot_huber.py`, `p0_autopsy_pilot_recency.py` | 예비 실험 → `out/p0_autopsy/pilot_*.json` |
| `out/p0_autopsy/replay_V*_r*.npz` | 반사실 Δ(phase 0, c_dec 0.3%). 약 5MB이고 다시 만들 수 있으니 커밋하지 않아도 됩니다 |
