# 주식 차트 스캔 리포트

코스피·코스닥 전종목 2,555개를 기술적 지표로 스캔한 결과입니다. 데이터 기준일 2026-08-07.

## 리포트

| 리포트 | 종목 수 | 내용 |
|---|---|---|
| [초입 종목](early.html) | 30 | 지표는 위로 돌아섰는데 가격은 아직 안 움직인 종목 |
| [TGB 전략](tgb.html) | 108 | G·T·B·U 네 지표 조건을 등급별로 판정 (홈런 11 / 강력 25 / 권고 20 / 주의 52) |
| [유사 종목](sim.html) | 254 | 기준 21종목과 같은 지표 흐름을 보이는 종목 |

각 리포트에서 **종목명을 클릭하면 6단 차트**(가격+그물망 / 거래량 / U / T / B / G)가 펼쳐집니다.

## 지표

| 기호 | 지표 | 계산 |
|---|---|---|
| **G** | Golden Buy/Sell | 적선 = (종가 ÷ 25일 최저 − 1)×100, 청선 = (25일 최고 ÷ 종가 − 1)×100 |
| **T** | TSI | True Strength Index (10, 30) + 시그널 8 |
| **B** | BPDI Hilo Index | RSI(35) 형태로 근사 |
| **U** | Ultimate Oscillator | (7, 14, 28) + 시그널 8 |
| — | 그물망 | MA 10·15·20·25·30·35 다발. 최단기가 최장기 위면 적색(상승 배열) |

지표는 대신증권 HTS 차트 이미지에서 각 선의 픽셀을 추출해 역추정했습니다. Golden은 상관계수 0.85~0.91, BPDI Hilo는 0.856 수준으로 원본과 일치합니다. TSI는 차트 범례의 파라미터를 그대로 사용했고, Ultimate Oscillator는 표준 공식입니다.

미구현: 매수·매도 화살표(HTS 자체 신호), 자동추세선, 월봉 확인, 다이버전스.

## 데이터

- 시세: KRX (FinanceDataReader)
- 차트: 대신증권 스타일로 재현, 종목당 392장
- CSV: [early.csv](early.csv) · [tgb.csv](tgb.csv) · [sim.csv](sim.csv)

## 유의사항

기술적 지표 조건에 맞는 종목을 기계적으로 나열한 자료입니다. 재무·수급·뉴스는 반영되어 있지 않으며, 특정 종목의 매수·매도를 권유하지 않습니다. 지표가 상승으로 돌아섰다고 해서 반드시 주가 상승으로 이어지지는 않습니다. 투자 판단과 그 결과는 투자자 본인에게 귀속됩니다.
