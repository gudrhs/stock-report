# 원화 비트코인 일별 값 (현실 점검용)

`btc/research/recost.py`가 원화 기준 계산(현금은 원화, 비트코인은 원화 가격)에 쓰는 일별 값입니다.
이 저장소의 사전 등록 문서 `btc/research/success_criteria.md`의 '현실 점검 (2026-09-28 02:10 UTC 등록)' 절을 따릅니다.
업비트·빗썸 같은 거래소 API는 이 작업 환경에서 막혀 있습니다. 그래서 GitHub 공개 저장소에 저장된 사본을 받아 합쳤습니다.
출처별 URL·커밋·라이선스는 `SOURCES_manifest.json`에, 합친 방법은 `build_krw.py`에 있습니다.
`build_krw.py`는 원자료를 받은 작업 폴더 기준으로 작성되어 있어, 이 저장소에서 그대로 실행되지는 않습니다.

## `krw_daily.csv` (2014-01-01 ~ 2026-09-25, UTC 날짜)

| 열 | 뜻 |
|---|---|
| `krw_open` | 그날 00:00 UTC(= 09:00 KST)의 원화 비트코인 가격. 2017-10-23까지는 코빗, 2017-10-24(업비트 정식 개장)부터는 업비트 |
| `krw_src` | `korbit_last_trade_0000`: 코빗의 00:00 UTC 직전 마지막 체결가(bitcoincharts 체결 자료) · `upbit_day_open`: 업비트 일봉 시가(일봉 경계 09:00 KST = 00:00 UTC) |
| `korbit_age_min` | 코빗 값이 00:00보다 몇 분 앞선 체결인지 (2015~2017-10에 60분 넘는 날 17일) |
| `upbit_close` | 업비트 일봉 종가 (업비트 구간만, 근사 오차 점검용) |
| `usdkrw_0000` | 00:00 UTC 기준 원/달러. FRED DEXKOUS 전날 값을 쓰고, FRED 자료가 끝난 뒤(2026-09-19~)에는 openexchangerates 00:04 UTC 스냅숏 |

- 업비트 값은 GitHub 공개 저장소 다섯 곳의 업비트 API 저장본을 합친 것입니다. 저장본끼리 겹치는 날은 종가가 같습니다. 시가는 한 저장본이 29~31일 동안 최대 0.11% 달랐습니다.
- 김치프리미엄(원화 가격 ÷ (비트스탬프 × 환율) − 1)은 2018-01-08에 57.7%로 가장 높았습니다. 2022~2025년에는 약 1~3%, 2026년에는 약 0%입니다.
  이 값은 독립된 다른 계산(업비트 ÷ 바이낸스 × ECB 환율)과 상관 0.992로 맞습니다.
- 제3자 원자료 파일(체결 자료, 원래 CSV·JSON)은 올리지 않았습니다. 계산에 쓰는 일별 값만 출처와 함께 올립니다.
